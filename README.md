## 💡 Key Concepts Practiced

Some of the important concepts reinforced through these assignments:

```python
# Indexing & Slicing
array[start:stop:step]

# Aggregation
array.mean()
array.sum()
array.max()
array.min()

# Boolean Filtering
array[array > value]

# Sorting
np.sort(array)

# Finding Positions
np.argmax(array)
np.argmin(array)
np.where(condition)

# Broadcasting
array * scale

# Min-Max Normalization
(x - x.min()) / (x.max() - x.min())
```
